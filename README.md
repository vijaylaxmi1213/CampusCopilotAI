# CampusCopilot AI

CampusCopilot AI is an Agentic Web platform designed to help students discover internships, scholarships, coding contests, and job opportunities using autonomous AI-powered workflows.
The project demonstrates how AI agents can browse websites, extract useful information, analyze content, and provide intelligent recommendations automatically.

# Features

* AI-powered search assistant
* Autonomous web browsing
* Browser automation using Playwright
* Internship and job search
* Skill detection from webpages
* Smart recommendations
* Search history tracking
* Interactive modern UI
* Real-time web extraction


# Problem Statement

Students spend significant time manually searching across multiple websites for internships, scholarships, coding contests, and placement opportunities.
CampusCopilot AI solves this problem by automating web browsing and information extraction using an intelligent AI agent.


# Solution

Users can enter queries such as:

* Java internships
* Python jobs
* Coding contests
* Engineering scholarships

The AI agent then:

1. Searches the web automatically
2. Opens websites
3. Extracts useful information
4. Detects required skills
5. Displays summarized recommendations
